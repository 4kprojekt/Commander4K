Commander4K

Everything is a folder. Commander4K by 4Kprojekt is a fast, keyboard-driven, open-source (MIT) dual-pane file manager for Windows 11, in the tradition of Norton Commander, Midnight Commander and Total Commander. Written in C# on .NET 10 with Avalonia UI, native on x64 and ARM64.

Download (ZIP / MSI) Source code on GitHub Plugin guide

What it does

  • A mailbox, a photo gallery, an SFTP/FTP server, a Linux box over SSH, this PC's hardware or a dashboard of live cards — each is a folder, described by small .c4k files in it.
  • Streams huge folders and network shares without freezing the UI; LAN discovery (SMB, SSH, FTP, mDNS), archives, Windows Registry as a folder.
  • Out-of-process plugins in Python, Node.js, PowerShell or .NET with declared, audited permissions.
  • Built-in MCP server: Claude Code, Codex, Gemini CLI, Cursor or VS Code can build dashboards, skins and plugins, and the app asks before anything is saved.
  • Skins: modern, Norton Commander, Midnight Commander, Total Commander classic, or your own.
